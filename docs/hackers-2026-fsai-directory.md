# FSAI member directory vs our flight-school list

Generated by `research/FlightSchoolMapping/scripts/56_fsai_directory.py`; do not edit by hand.

> **Headline.** The Flight School Association International's public directory lists 567 member entries (547 after collapsing repeats). 385 are US (or unaddressed) flight-training providers, 284 by their own tags and 101 by name alone. 241 match a school already in our list; 144 do not.

## Source and method

- FSAI was the Flight School Association of North America (FSANA) until February 2026. Its directory is linked as "School search" on fsai.org and needs no login. It lists members only, so it is a sample of schools that pay dues, not a census.
- Pulled 2026-11-04 by running the page's own search in a browser: one empty search (every entry), then one search per Classification and per Type to tag entries (the server ignores Product Category on its own, so it was not used). The results endpoint refuses requests made outside the page, so the pull ran in the page at about one request a second.
- Kinds: *training* if any tag is a flight-school classification or a training type (Part 141, Part 61, private pilot and so on); *vendor* if tagged only with other things (software, financing, examiners, consultants); *school_name* if untagged but the name reads as flight training; *individual* if the name has no organization word and there is no contact line; *untagged* otherwise. Individuals' names and addresses are not reproduced here.
- Training and school_name entries in the US, or with no address at all, were matched against `output/flight_line.json` with `probes/match_external_school_lists.py` (domain, exact name, street address, fuzzy name within a state; the same rules as the state lists in `docs/hackers-2026-state-registries.md`). Entries with no address get a nationwide exact-name check (`exact_any_state`).

## Reproduce

Open the directory page in a browser and run `scripts/probes/fsai_directory_pull.js` in its console; it pulls every entry and tag and saves `fsai_raw.json` as a download. Move that to `data/research-2026-11/fsai/`, then, from `research/FlightSchoolMapping/`:

```
python scripts/56_fsai_directory.py data/research-2026-11/fsai/fsai_raw.json data/research-2026-11/fsai
```
